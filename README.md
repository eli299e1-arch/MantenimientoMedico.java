
# Sistema de Mantenimiento Médico

## Descripción

Sistema desarrollado para la gestión y control de pacientes en una clínica médica. Permite administrar información de pacientes, médicos y citas, facilitando la organización de los servicios de salud y mejorando el seguimiento de la atención médica.

## ¿Qué problema resuelve?

Este sistema ayuda a centralizar la información médica y administrativa de una clínica, reduciendo errores en la gestión de pacientes, optimizando la programación de citas y facilitando la generación de reportes para el control y seguimiento de las actividades realizadas.

## Funcionalidades

- Registro de pacientes.
- Gestión de médicos.
- Control y programación de citas médicas.
- Consulta de información almacenada.
- Generación de reportes.

## Tecnologías utilizadas

- Java
- MySQL
- JasperReports (.jrxml)
- Proyecto realizado para la materia de Programación - UTP

## Instalación y ejecución

1. Clonar o descargar el repositorio.

2. Abrir el proyecto en un entorno de desarrollo compatible con Java, como NetBeans o Visual Studio Code.

3. Configurar la conexión a la base de datos MySQL.

4. Crear la base de datos e importar las tablas requeridas por el sistema.

5. Compilar el proyecto.

6. Ejecutar la clase principal del sistema.

7. Iniciar sesión o acceder al menú principal.

8. Utilizar las opciones disponibles para registrar pacientes, administrar médicos, gestionar citas y generar reportes.
